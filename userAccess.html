ThoughtSpot Group Access Viewer

Groups + Org-wide share/discoverability report

Clarification: REST can reliably list saved Liveboards/Answers/Models. “Unsaved session answers” are not a stable, reportable object type via REST.

Compatibility: This app auto-detects whether your cluster supports Orgs. If Orgs are not supported, it runs in single-org mode (no org selector, no org scoping).

Performance: Org-wide metadata/search is fetched in pages (to avoid 504 gateway timeouts).

NOTE: This app does not report on system objects.
Populated from POST /api/rest/2.0/orgs/search. UI shows org name, API calls use org id (as org_id).
